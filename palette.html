Palette and highlighting rules

The house standard for study material. It defines five text marks, seven callout boxes, and the rules for when each is used — and it validates itself, so a value that stops passing stops the build. Written for one project and intended for the next: nothing below is specific to its subject.

Generated from _rebuild/palette.py. Every figure on this page is measured when it is generated, so the page and the site it documents are the same numbers and cannot drift.

What each mark means

These are the whole vocabulary. The discipline is that most of a page carries none of them — roughly one mark per card or table row, and around a fifth of entries with none at all. That is what makes a marked span register.

  1. Anchor — the point, in as few words as possible. The test is blunt: read the anchor alone, with the rest of the sentence covered, and you should be able to say what the thing is. Not the most quotable fragment and not the most distinctive one for scanning — the definition, compressed. "needs, capabilities and motivations" passes. "fit for the project context" fails: it repeats the heading and tells you nothing. At most one per card, around six words, and no anchor at all is better than a circular one.
  2. Side A and Side B — the two halves of a distinction. Read them together, on their own, and the distinction should be stated. Both halves parallel; both carrying their own subject. "occurs in sequence" / "occur iteratively throughout the lifecycle" passes. "the seventh" / "not an aspect of performance" fails, because neither half says what it is about. Never one without the other; up to ten words each, since a half needs its own subject and verb.
  3. Trap — a negation or a reversal, and only that. Skim past it and the sentence says the opposite. On examinable material these are the highest-value spans on the page, because each one is a wrong answer somebody would otherwise pick.
  4. Value — letters standing for words, or a hard figure. Rare, and deliberately so: in the 202-entry corpus this was measured against, it appeared 21 times and every single use was an acronym expansion or a literal like a date. A bare small number is not a value. A list of four verbs is certainly not one.

The rules the palette enforces

  1. Two measures, not one. Can you read the marked words? is WCAG contrast between a mark's ink and its own fill, and needs 4.5:1. Does the mark read as a mark? is CIEDE2000 between the mark's fill and the surface behind it, and needs 8. Using contrast for both produced 45 false failures the first time this was audited: pale amber on white is a 1.1 contrast ratio and obviously visible, because the difference is hue, not lightness.
  2. Never tint a box with a mark's own colour. A box cannot be tinted with a hue and also show a mark of that hue inside it — the mark measures dE 0 and vanishes. If a box needs to keep the family colour of a mark it hosts, its fill backs off to a whisper and the 5px edge and the label carry the identity instead.
  3. A mark may be distinct; it may not be brighter than its page. A fill much lighter than the surface it sits on is a lamp rather than a mark. The ceiling is 4.5:1 and it is directional — a dark chip on a light page is comfortable at any ratio.
  4. Some boxes suppress marks. A box that is already one signal makes a mark inside it redundant: danger, which is shouting, and hook, which has no prose to mark. A trap box does not suppress: it is often where the sharpest contrast on a page sits, and taking the pair colours out of that sentence loses the thing worth seeing. Suppression is generated CSS and it is asserted — note that a comma list binds a descendant combinator to its last selector only, so the scope must be repeated per box.
  5. One signal per word, with exactly one exception. Never a mark inside a link, never a link inside a mark, never a mark nested in another. The exception is value: the other four marks say something about the argument of a sentence and would compete with a link, but value says something about the form of a word — this is an initialism — which does not. So an acronym that is also a glossary term carries both.
  6. A coloured box sets its own body ink and its own link colour. Text takes the box's ink, not the page's, and a glossary link inside a box takes the box's ink too: page-blue underlining on a red field reads as a mistake.
  7. Every mark dies in test mode. A coloured span during recall hands over the answer as surely as the text would.
  8. A mark never breaks across two lines. Half a coloured box at the end of one line and half at the start of the next reads as damage. Spans short enough that pinning them cannot cause overflow are pinned at build time; anything longer renders its fill, padding and corners on every fragment so each looks deliberate.
  9. Every value mark is tappable. A value is an initialism or a literal — exactly the kind of word a reader does not already know. Leaving one without a definition behind it is the one case where a mark actively withholds. If a term has no glossary entry yet, write one rather than dropping the mark.
  10. Any mark that could carry a definition, does. Where a marked phrase is itself a defined term, the mark and the link are the same element rather than two nested ones.

Using this on another project

Three files, none of which know anything about the subject matter.

palette_lib.pyColour maths — WCAG contrast, CIELAB, CIEDE2000. No project content.
palette.pyThe palette itself. Every colour, every rule, validated on import and emitted as CSS. Change a colour here and nowhere else.
palette_doc.pyGenerates this page from the above.
  1. Copy the three files. Point your build at palette.css() and append it last in the stylesheet, so it wins over anything hand-written.
  2. Change the BASE surfaces to your own page and card colours. Everything else re-validates against them automatically; if a mark stops passing you will be told which and by how much.
  3. Add or remove boxes in BOXES. Each needs a fill, an edge, a body ink, a label ink, and marks saying whether highlights survive inside it.
  4. Run python3 palette_doc.py to regenerate this page for the new project. It is the handover document.
  5. Keep the assertions. They exist because each one caught a real defect: an invisible mark, a mark that glared, a suppression rule that silently applied to one box out of three, a value span that was neither an acronym nor a figure.
